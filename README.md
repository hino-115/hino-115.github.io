# hinoのポートフォリオ

個人で制作している作品を紹介するために、テレビゲームをイメージしたポートフォリオサイトを作りました。

ブラウン管テレビ風の画面とコントローラーを配置し、ゲームのメニューを操作するようにサイトを閲覧できます。「スタート」からメニューを開き、十字キーで「自己紹介」または「ポートフォリオ」を選びます。丸い「A」ボタンで決定し、「B」ボタンで前の画面に戻れます。キーボードでも操作できます。

「自己紹介」と「ポートフォリオ」の内容は、それぞれ別のHTMLファイルから読み込み、テレビの枠内に表示しています。Portfolioでは、コーヒー豆向けの小規模在庫管理システムを紹介しています。

## 使用技術

HTML・CSS・JavaScript

## 動作確認

サイトのファイルを同じフォルダに置き、`index.html` をブラウザで開いてください。
